How the Google Sheets tools work

  1. Make a copy from the link in the setup guide: a blank sheet with the tool attached.
  2. Run the setup from the menu in the sheet. It asks for your store's details once.
  3. Use it. Nobody else, including whoever built it, can see your copy.

No-setup tools skip all that: open the page and start. Your data stays in that browser on that computer and is never uploaded. Each guide says how to back it up.

More tools are added once their setup has been tested from scratch.
