Chick-fil-A Restaurant Tools

Free tools built on Google Sheets. Each one starts as a blank copy in your own Google account, so your data stays yours, and there's no code to touch.

🍽️ Catering Quote Tool

Build, email and print catering quotes in a couple of minutes. Tracks POs, tax-exempt certificates, delivery days and follow-ups, for one store or two.

How every tool works

  1. Make a copy from the link in the setup guide: a blank sheet with the tool attached.
  2. Run the setup from the menu in the sheet. It asks for your store's details once.
  3. Use it. Nobody else, including whoever built it, can see your copy.
